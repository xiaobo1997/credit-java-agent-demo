```
├─────────────────────────────────────────────┤
```

## 核心数据流

```
POST /api/agent/review
  { name, idCard, amount, purpose }
           │
           ▼
    AgentController
      ├─ 构建 application 文本
      ├─ 生成/获取 memoryId
           │
           ▼
    CreditReviewAgent.review(memoryId, application)
      │
      ├─ 1. 构建 Prompt = SystemMessage + 历史消息(Memory) + UserMessage
      ├─ 2. 构建 Tools 列表（从 @Tool 注解扫描）
      ├─ 3. 发送给 DeepSeek（OpenAI 格式）
      │
      ▼
    DeepSeek 返回 tool_calls
      { function: "checkCredit", arguments: { idCard: "320102..." } }
           │
           ▼
    LangChain4j 反射调用
      CreditCheckTool.checkCredit("320102...")
      → "征信分数: 795, 等级: 优秀"
           │
           ▼
    结果再次发给 DeepSeek
      → "审核结论：通过。征信分数 795..."
           │
           ▼
    返回给用户
      { memoryId, application, result }
```

## Agent 决策流程

```
收到借款申请
     │
     ▼
LLM 分析用户意图
     │
     ├─ "需要查征信" → 调用 checkCredit(idCard)
     │                      │
     │                      ▼
     │                  获取征信分数
     │                      │
     │         ┌────────────┼────────────┐
     │         ▼            ▼            ▼
     │       >=750       650-749        <650
     │       "通过"      "人工复核"     "拒绝"
     │
     └─ 综合信息，输出审核结论 + 理由 + 建议额度
```

## Bean 依赖关系

```
    │

```

## 为什么是信贷场景

用信贷审核做 Agent 学习场景有三重好处：

1. **业务熟悉**：场景理解深刻，能专注学 Agent 技术
2. **技术特色**：信贷 + AI Agent = 金融科技方向，差异化竞争力
3. **Tool Calling 自然**：征信查询、反欺诈、流水分析都是天然的 Tool 场景
